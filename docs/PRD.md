## 1. 产品概述

### 1.1 产品定位

**车修宝**是一款面向汽车后市场门店的 SaaS 管理系统，覆盖维修、洗美、轮胎、装饰等业态。核心价值链：

```
车主 ←→ 门店前台 ←→ 车间 ←→ 库存/财务 ←→ 总部（连锁）
```

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 门店老板/店长 | 经营决策、报表、权限管理 |
| 前台/服务顾问 | 接车、开单、报价、收银 |
| 技师/质检 | 接单、施工、完工 |
| 仓管/采购 | 库存、采购、入库出库 |
| 车主（C 端） | 预约、查单、评价（二期） |

### 1.3 产品目标

- **降本增效**：接车开单 ≤ 30 秒，工单全流程在线
- **标准化**：统一服务流程，减少人为差错
- **数据驱动**：实时掌握营收、利润、客户、库存
- **客户留存**：会员、卡券、回访提升复购

### 1.4 分阶段交付

| 阶段 | 范围 | 目标 |
|------|------|------|
| **MVP（一期）** | 接车开单、透明车间、收银、基础库存、简单报表 | 单店可跑通完整业务闭环 |
| **二期** | 会员营销、CRM、员工业绩、车主小程序 | 增长与留存 |
| **三期** | 供应链、VIN 智能、AI 辅助、电子档案、连锁 | 差异化与规模化 |

## 3. 核心业务流程

### 3.1 标准维修流程

```
接车登记 → 环检预检 → 检测 → 报价 → 客户确认
    → 派工 → 领料 → 施工 → 质检 → 结算收银 → 交车 → 回访
```

### 3.2 工单状态流转

```
                    ┌─────────┐
                    │  已取消  │
                    └────▲────┘
                         │ (任意未结算状态)
┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
│ 待预检  │ → │ 待检测  │ → │ 待报价  │ → │ 待确认  │ → │ 施工中  │ → │ 待质检  │ → │ 待结算  │ → 已完成
└────────┘   └────────┘   └────────┘   └────────┘   └────────┘   └────────┘   └────────┘
  接车        环检完成      检测完成      报价完成      派工开工      施工完成      质检通过
```

### 3.3 库存联动

```
工单确认配件 → 锁定库存 → 领料出库 → 扣减库存
                    ↓ (取消/退料)
               释放/回退库存
```

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|------|------|
| 页面加载 | 首屏 ≤ 2s |
| API 响应 | P95 ≤ 500ms |
| 并发 | 单店 20 人同时在线 |
| 数据量 | 单店 10 万条工单无感 |

### 4.2 安全

- 数据传输 HTTPS 加密
- 密码 bcrypt 加密存储
- RBAC 角色权限控制
- 敏感操作日志审计
- 租户数据隔离（SaaS 多门店）

### 4.3 可用性

- 系统可用性 ≥ 99.9%
- 支持 PC Web + 移动端 H5/App
- 关键操作支持离线草稿（移动端，二期）

### 4.4 兼容性

- PC：Chrome、Edge、Safari 最新两个大版本
- 移动：iOS 14+、Android 8+
- 小程序：微信基础库 2.20+
